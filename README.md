# [時代光譜](https://era-palette.vercel.app/) 
> 歷史影像與色彩氛圍修復系統

一款結合理事影像、色彩科學與遊戲化學習的互動網頁遊戲，玩家將化身為**時光觀測員**，透過分析歷史照片中的色彩特徵與時代氛圍，調整影像參數，逐步修復失真的歷史記憶，還原最近真實時代的色彩樣貌

## 遊戲理念
不同年代的影像往往受到攝影技術、底片特性、環境光源與保存狀況的影響，而呈現出獨特的色彩風格。
<時代影像館>希望透過遊戲化的互動方式，讓玩家在修復影像的過程中：
- 認識不同年代的色彩特徵
- 觀察歷史場景的氛圍差異
- 學習色彩的基礎概念
- 建立對歷史文化的探索興趣
## 核心特色
- **歷史影像探索**：精選多個具代表性的歷史場景（如 1980 年代繁華的東京新宿、低解析度帶有類比噪點的 VHS 錄影帶年代等）。
- **色彩修復系統**：提供直覺的滑桿控制介面，可調整色溫、飽和度、暗角、對比度與曝光度，所有調整都會即時反映於畫面中，提供直觀的修復體驗。
- **真實色改觀測功能**：經過第一版的體驗回饋後，為了降低難度，每個關卡提供**歷史真實色彩觀測**玩家可以通過長按按鈕暫時查看正確色彩版本、觀察歷史色彩特徵以及作為修復的參考，不過觀測次數有限制，因此不會變得過於簡單。
- **智慧評分系統**：從「暖色氛圍」、「色彩還原」與「畫面質感」三個維度進行精密比對，修復完成後生成精準度百分比與歷史評級（S/A/B/C）。
- **時光碎片收集機制**：修復影像後，系統會根據還原精準度發放相應數量的「時光碎片」。累積的碎片不僅代表修復成就，更是解鎖後續未知歷史節點核心權限的關鍵代幣。
- **時光修復日誌（回顧圖鑑）**：內建完善的回顧系統。自動建檔玩家修復成功的完美渲染版本、歷史最高得分、獲得評級，並詳細記錄每一關專屬的「氛圍特徵碼」，讓玩家能隨時翻閱、回溯專屬於自己的時光觀測軌跡。

## 技術使用
- **Frontend**：React、TypeScript、Vite
- **UI/Styling**：Tailwind Css v4、自訂玻璃擬態介面、動態光影效果、CSS Filter 即時影像處理
- **Animation**：motion/react (Framer Motion)
- **Icons**：Lucide React

## 專案結構
```text
src/
├── assets/          # 靜態資源與圖片
├── components/      # 共用元件
├── constants.ts     # 關卡資料與歷史節點設定
├── types.ts         # 核心型別定義 (GameState, Filters, Era)
├── App.tsx          # 主遊戲邏輯與狀態管理
├── index.css        # 全域樣式
└── main.tsx         # 應用程式進入點
```

## 開發環境配置
### 1. 複製專案
```bash
git clone <repository-url>
cd era-palette
```

### 2. 安裝依賴
```bash
npm install
```

### 3. 啟動在地開發伺服器
```bash
npm run dev
```
