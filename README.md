# [時代光譜](https://era-palette.vercel.app/) (Era Palette) — 歷史影像與色彩氛圍修復系統

一個基於 React、TypeScript 與 Tailwind CSS 開發的沉浸式互動網頁遊戲。玩家將扮演「時光觀測員」，深入不同世紀與城市的視覺碎片，透過調校色溫、飽和度、曝光度等氛圍參數，修復並還原歷史真實色彩。

## 核心特色
- **時光節點接入**：精選多個具代表性的歷史場景（如 1980 年代繁華的東京新宿、低解析度帶有類比噪點的 VHS 錄影帶年代等）。
- **氛圍精密校準**：提供直覺的滑桿控制介面，可即時調整色溫、飽和度、顆粒感、對比度與曝光度。
- **智慧評分系統**：從「暖色氛圍」、「色彩還原」與「畫面質感」三個維度進行精密比對，修復完成後生成精準度百分比與歷史評級（S/A/B/C）。
- **時光碎片收集機制**：修復影像後，系統會根據還原精準度發放相應數量的「時光碎片」。累積的碎片不僅代表修復成就，更是解鎖後續未知歷史節點核心權限的關鍵代幣。
- **時光修復日誌（回顧圖鑑）**：內建完善的回顧系統。自動建檔玩家修復成功的完美渲染版本、歷史最高得分、獲得評級，並詳細記錄每一關專屬的「氛圍特徵碼」，讓玩家能隨時翻閱、回溯專屬於自己的時光觀測軌跡。

## 技術使用
- **前端框架**：React 18 / 19
- **程式語言**：TypeScript
- **樣式整合**：Tailwind CSS v4 (含自訂背景遮罩與動態濾鏡)
- **動畫效果**：motion/react (Framer Motion)
- **圖標庫**：Lucide React
- **建構工具**：Vite

## 專案結構
```text
src/
├── assets/          # 靜態資源與圖片
├── components/      # 可複用 UI 元件
├── constants.ts     # 歷史時代關卡數據 (ERAS) 與初始設定
├── types.ts         # 核心型別定義 (GameState, Filters, Era)
├── App.tsx          # 系統主控台、狀態管理與核心遊戲邏輯
├── index.css        # 全域樣式、自訂玻璃底層與動態噪點動畫
└── main.tsx         # 應用程式進入點
```

## 開發環境配置
### 1. 複製專案
```bash
git clone <repository-url>
cd era-palette
```

### 2. 安裝依賴
```bash
npm install
```

### 3. 啟動在地開發伺服器
```bash
npm run dev
```
